# Image sources

Every file under `public/images` is generated by `scripts/images.mjs` from a source in `assets/images` (committed). AVIF with a WebP fallback, fixed sizes, explicit dimensions in `src/content/images.ts`. No third-party images are downloaded.

| Output                            | Size     | Source                    | Origin and capture                                                                                                                                                                                              |
| --------------------------------- | -------- | ------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `cover.{avif,webp}`               | 1920×600 | `cover.jpg`               | Owner's own cover photo from the previous site; cropped to the 16:5 band from the top of the photo (the hero then anchors the band to its top edge).                                                            |
| `avatar.{avif,webp}`              | 320×320  | `avatar.jpg`              | Owner's own avatar from the previous site.                                                                                                                                                                      |
| `enact-cli.{avif,webp}`           | 800×500  | `enactjs.jpg`             | Owner's screenshot of the Enact site from the previous site; center-cropped to 16:10.                                                                                                                           |
| `enyo.{avif,webp}`                | 800×500  | `enyojs.jpg`              | Owner's screenshot of the Enyo site at 1280px wide from the previous site; cropped to 16:10 from the top so the header and hero stay. The domain now forwards to the Enact site, so no new capture is possible. |
| `svl-simulator.{avif,webp}`       | 800×500  | `svlsimulator.jpg`        | Owner's screenshot of the SVL Simulator site (owner was its primary author) from the previous site; center-cropped to 16:10.                                                                                    |
| `retailverse-web.{avif,webp}`     | 800×500  | `retailverse-web.png`     | Captured 2026-10-04 by `scripts/capture/retailverse.mjs` from the live RetailVerse Web viewer (WM4000HBA model) after the 3D model loaded. Owner's shipped work.                                                |
| `webos-homebrew.{avif,webp}`      | 800×500  | `webos-homebrew.png`      | `screenshot.png` from the owner's repository JayCanuck/webos-quick-install (`webos-quick-install-source.png`), framed to fill the slot by `scripts/capture/webos-homebrew.mjs`.                                 |
| `gamelist-utils-muos.{avif,webp}` | 800×500  | `gamelist-utils-muos.png` | Real `npx gamelist-utils --help` output captured locally and rendered in a terminal frame by `scripts/capture/gamelist-utils.mjs`.                                                                              |
| `not-found.{avif,webp}`           | 1920×600 | `404.jpg`                 | Owner's 404 backdrop from the previous site; center-cropped to the 16:5 band.                                                                                                                                   |
| `ufo-and-cow.svg`                 | 420×420  | `ufo-and-cow.svg`         | Owner's illustration from the previous site; copied as is.                                                                                                                                                      |

The six card images are one 800×500 file each: every card slot is the same width and at most 355px wide, so one file covers 2x screens (D15 amendment). The cover and 404 backdrops keep their `-640` and `-1280` variants.

Favicons `src/app/icon.png` (32×32) and `src/app/apple-icon.png` (180×180) are also generated from `avatar.jpg`.
