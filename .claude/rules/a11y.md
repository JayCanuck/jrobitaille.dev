# Accessibility rules

- Landmarks: `header`, `nav`, `main`, `footer`; every `section` has a heading. One `h1` per page.
- Skip link is the first focusable element in `body`. Visible `:focus-visible` styles on every interactive element.
- WCAG AA contrast in both light and dark schemes. Check both before calling it done.
- Native elements first; ARIA only where native semantics do not cover the need. No `role` on elements that already carry it.
- Honor `prefers-reduced-motion` wherever motion exists. The static version is the default; motion is the enhancement.
- Everything is keyboard reachable and operable: cards, links, timeline nodes, any island.
- Images: explicit `width` and `height`, meaningful `alt`, or `alt=""` when decorative.
- External links carry `rel="noopener noreferrer"`; no `target="_blank"` without telling the user.
- Lighthouse a11y 100 and axe clean are CI gates. Run `npm run e2e` after UI changes.
